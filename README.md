# Slate

A theme for the wicked.

![GitHub License](https://img.shields.io/github/license/dsafxP/slate?style=for-the-badge&labelColor=2d2a2e&color=ddddda)

</div>

A monochrome-like color scheme with desaturated accents, bright whites, and deep blacks.

Desaturated colors are easy on the eyes, while high-contrast backgrounds keep content readable and make accents stand out.
