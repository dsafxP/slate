# Slate for Godot

Godot builds the whole editor palette from two colors plus two sliders.

Start from the Custom preset, then set these under `Editor → Editor Settings → Interface → Theme`.

## Slate Dark

| Setting          | Value     |
| ---------------- | --------- |
| Base Color       | `#1d1b1d` |
| Accent Color     | `#a893af` |
| Contrast         | `0.18`    |
| Icon Saturation  | `0.5`     |

## Slate Light

| Setting          | Value     |
| ---------------- | --------- |
| Base Color       | `#ffffff` |
| Accent Color     | `#7a688d` |
| Contrast         | `0.06`    |
| Icon Saturation  | `0.5`     |
